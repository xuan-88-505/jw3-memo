# 备忘录（JW3 Memo）

剑网3（旗舰端）宏和奇穴的统一管理工具，支持 Windows 和 Mac。

备忘录待在系统托盘（Windows 任务栏右下角）或菜单栏（Mac 屏幕顶部）里。点图标或按快捷键打开面板，查看当前角色的宏和奇穴，一键复制宏。备忘录不读写游戏文件，不模拟按键。自己用不需要登录；和亲友一起用时，加入亲友团只要邀请码和昵称。

## 下载

到 [Releases](https://github.com/xuan-88-505/jw3-memo/releases) 下载最新版本：

| 系统 | 下载这个文件 |
| --- | --- |
| Windows 10 / 11 | `JW3-Memo_*_windows_x64-setup.exe` |
| Mac（M 芯片和 Intel 芯片都可以） | `JW3-Memo_*_darwin_universal.dmg` |

安装后，软件在开始菜单、启动台和「应用程序」里叫 **JW3 Memo**，打开后界面里叫「备忘录」。Mac 自带的「备忘录」也叫这个名字，用英文名可以避免在启动台和聚焦搜索里混淆。

## 第一次打开

备忘录没有购买签名证书，系统第一次会拦一下。放行一次以后就不会再拦。

**Windows**：出现「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。

**Mac**：打开 dmg，把「JW3 Memo」拖进「应用程序」。第一次打开被拦住时，到「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。如果提示「已损坏，无法打开」，打开「终端」运行下面这行，再重新打开：

```
xattr -cr "/Applications/JW3 Memo.app"
```

## 升级到新版本

2.1.0 之后的新版本带一键更新。软件打开后会在后台检查新版本，只检查，不自动下载。有新版本时，管理窗口的「设置」和面板的通知铃铛上会出现金色小点。点「更新并重启」后，软件先保存数据并备份，再下载、安装，装好后自动重新打开。更新包有签名，软件会校验，不是我们发布的包装不上。

2.1.0 和更早的版本没有一键更新，要手动装一次新版。一键更新失败时，也可以手动装：「设置 → 检查更新」会打开下载页，下载新版安装包后直接安装，覆盖旧版即可。不用先卸载，数据都还在。

1. 安装前先退出旧版：右键托盘图标（Mac 上点菜单栏图标），选「退出」。
2. Windows：运行新的 `setup.exe`，装到原来的位置。Mac：打开新的 dmg，把「JW3 Memo」拖进「应用程序」，提示已存在时选「替换」。
3. 新版第一次打开时，系统可能还会拦一次，和第一次安装时一样放行（见上面「第一次打开」）。

从 1.x 升级到 2.x 时，第一次打开会把数据转换成新格式，转换后不建议再装回 1.x。

## 从「同调」1.0.0 升级

1.0.0 叫「同调」。新版本换了名字，会作为一个新软件安装，旧版不会被自动替换。数据存放的位置没变，新版打开后数据都还在。

1. 打开旧版「同调」，在「设置」里关掉「开机自动启动」。
2. 右键托盘图标（Mac 上点菜单栏图标），选「退出」。
3. 删除旧版：
   - Windows：「设置 → 应用 → 已安装的应用」里找到「同调」，点「卸载」。卸载时**不要勾选**「删除应用程序数据」。
   - Mac：把「应用程序」里的「同调」拖进废纸篓。
4. 安装新版 JW3 Memo。

旧版没删时，两个版本会互相占用：打开新版只会把旧版的窗口叫出来。

## 使用

| 操作 | Windows | Mac |
| --- | --- | --- |
| 打开或收起面板 | 点托盘图标，或按 `Ctrl+Alt+Q` | 点菜单栏图标，或按 `⌃⌥Q` |
| 打开管理窗口 | 面板右上角的窗口图标，或右键托盘图标 | 面板右上角的窗口图标 |
| 移动面板 | 按住面板顶部拖动，双击顶部回到原位 | 同左 |
| 面板不自动收起 | 点面板上的图钉 | 同左 |

快捷键可以在「设置」里改。如果和游戏里的按键冲突，换一个组合即可。

## 数据

数据存在当前这台电脑上：

- Windows：`%APPDATA%\com.xuan88.tongdiao\data.json`
- Mac：`~/Library/Application Support/com.xuan88.tongdiao/data.json`

文件夹名里的 `tongdiao` 是旧名字。为了让升级后还能读到原来的数据，这个名字不改。

没加入亲友团时，数据只在这台电脑上。要搬到另一台电脑，在「设置 → 数据」里导出，再到另一台电脑上导入。导入会替换那台电脑上原有的数据。加入亲友团后不能导入，要先退出登录。

加入亲友团后，数据会同步到服务器，每台登录的电脑都会自动同步。断网时照常使用，联网后再同步。

## 亲友团

在管理窗口左侧点「亲友团」：

- **创建亲友团**：填亲友团名字和你的昵称。你是管理员，本机的方案、角色和记录会一起带进去。
- **用邀请码加入**：填管理员给你的邀请码（`TD-` 开头）和你的昵称。昵称在亲友团里不能重复。
- **在第二台电脑登录**：到第二台电脑的亲友团页，点「在别的电脑加入过？登录」，有两种方式：
  - 账号密码：先在第一台电脑的「设置 → 账号」里点「设置登录密码」，自己定用户名和密码，不需要邮箱。设置是可选的，不设也能照常用。
  - 登录码：在第一台电脑的「设置 → 账号」里点「生成登录码」，在第二台电脑输入 8 位登录码。登录码 10 分钟内有效，只能用一次。

权限：

| 权限 | 能做什么 |
| --- | --- |
| 管理员 | 全部操作；改成员权限、移除成员、重置邀请码、改亲友团名字；删除任何人的打本记录和避雷 |
| 编辑 | 改方案；添加和修改打本记录、避雷；删除自己加的记录 |
| 只读 | 看方案和记录。新加入的成员默认只读，由管理员改成编辑 |

不论什么权限，自己的角色、配装、便签和链接都由自己管理，别人改不了。配装和便签只有自己能看到；链接默认亲友团可见，可以改成仅自己。

两个人同时改了同一个方案时，后同步的人会看到两份改动的对比，自己选保留哪一份。先保存的那份已经在修改记录里，不会被覆盖。加入、登录和退出前，备忘录会先把本机数据复制一份 `data.backup-时间.json`，放在数据文件旁边，最多留 5 份。

服务器在境外（`tongdiao-k5ujnxu8.manus.space`），国内能访问，每次同步大约 1–2 秒。

## 开发

前端是 React + Vite + TypeScript，桌面壳是 Tauri 2（`src-tauri/`）。

- `pnpm dev:static`：只跑网页原型，浏览器打开 `http://localhost:3000`。
- `pnpm tauri dev`：以桌面应用运行。
- `pnpm tauri build`：在本机打包。
- 推送 `v` 开头的标签（如 `v1.0.2`）后，GitHub Actions 会在 Windows 和 Mac 上打包，并发布到 Releases。版本号要在 `package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 里一起改，`pnpm test` 会检查它们是否一致。
- 一键更新的签名和发布步骤见 [`tools/release/README.md`](tools/release/README.md)。
- 本地存储键、事件名、`identifier`（`com.xuan88.tongdiao`）和 Rust 包名仍用 `tongdiao`。改了会导致已有数据读不到，不要改。
